# Matt Pocock Skill Provenance

The selected skill folders under `.agents/skills/` are vendored from [mattpocock/skills](https://github.com/mattpocock/skills) for repository-local Codex discovery. The source project is MIT licensed; retain this attribution and its upstream [LICENSE](https://github.com/mattpocock/skills/blob/main/LICENSE) whenever these copies are redistributed.

Installed workflow set:

* `setup-matt-pocock-skills`, `grill-with-docs`, `grilling`, `triage`
* `domain-modeling`, `codebase-design`, `prototype`
* `to-spec`, `to-tickets`, `wayfinder`, `implement`, `tdd`, `code-review`

`ultimatecoders-issue-flow` is project-local. It adds the UltimateCoders tracker fallback and Trellis handoff without modifying the vendored upstream skills.
