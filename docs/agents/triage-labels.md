# Triage Labels

Matt skills use these canonical roles. In GitHub mode, map them to same-named repository labels after verifying the labels exist. In local mode, record the canonical value in a ticket's `Status:` field.

| Role | Tracker label / local value | Meaning |
|---|---|---|
| `bug` | `bug` | Confirmed broken behaviour |
| `enhancement` | `enhancement` | New or improved behaviour |
| `needs-triage` | `needs-triage` | Needs maintainer evaluation |
| `needs-info` | `needs-info` | Waiting for required information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an agent to take |
| `ready-for-human` | `ready-for-human` | Requires human judgement or access |
| `wontfix` | `wontfix` | Intentionally not actioned |

Do not create missing GitHub labels during discovery or setup. Ask for approval when a live publication needs one.
