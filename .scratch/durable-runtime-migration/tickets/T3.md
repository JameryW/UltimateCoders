## What to build

Rust 图状态机与 commit-once：
1. Node 状态集 CREATED/READY/SCHEDULED/RUNNING/WAITING/SUCCEEDED/FAILED/CANCELLED/SKIPPED + graph/node `version` CAS。
2. `NodeCompletion`（node_id, winning_attempt_id, result_ref）`INSERT … ON CONFLICT DO NOTHING` = 唯一终局写入；依赖满足从 committed 状态重推 READY（吸收现有 get_ready_subtasks）。
3. attempt 生命周期：心跳 + 超时判定；`reassign_stale_assigned_subtasks`（server.rs L2811–2879）替换为「超时 attempt → epoch fence → node 回 READY」。
4. 图级 pause 闸沿用现语义（D6：停派不停跑，resume 重算）。

## Acceptance criteria

- [ ] 双并发 commit 恰好一个 winner（真 PG 测试）。
- [ ] 迟到失败 attempt 不得覆盖已 commit 的 node。
- [ ] 菱形图测试：A→(B,C)→ 仅依赖 B 的 D 在 B commit 后立即 READY，不等 C。
- [ ] pause 期间 commit 的节点在 resume 重算中正确反映（D6 场景）。
