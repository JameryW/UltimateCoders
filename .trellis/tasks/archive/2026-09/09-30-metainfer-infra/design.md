# Design

`ultimate_coders.inference` owns validated domain types, BenchmarkRunner, Oracle, OptimizationWorkflow, MetaInferAdapter and ExecutionAdaptationGraph. It depends on standard Python and httpx, not MetaInfer source or GPU libraries. The UC agent adapter launches a module runner in the assigned git worktree. An explicitly configured inference task supplies upstream form parameters and argv benchmark commands. UC measures baseline, requests a candidate, optionally imports generated outputs with an explicit apply argv, measures candidate and accepts/rolls back. Iterations feed previous Oracle reasons into raw_request.

Artifacts live outside the candidate git tree in a task-owned temporary directory. Each candidate requires a clean dedicated git worktree and records HEAD plus the exact newly added paths, so rejection restores only the candidate changes. Read-only analysis has no performance acceptance claim. Structured output retains backend state/iterations/graph URLs, local graph and benchmark history. The Worker writes accepted structured evidence through its existing shared-memory helper. HTTP schema discovery determines supported fields and defaults; no opaque final_status is treated as correctness evidence.

Routing chooses the inference domain only when enabled and a task is explicitly supplied or strong inference context plus optimization/analysis intent matches. Prose alone cannot supply required backend paths; missing explicit task configuration fails clearly. The Python planner marks routed nodes with inference capability and carries task config over existing JSON agent_config. No execution-envelope/protobuf change is needed.
