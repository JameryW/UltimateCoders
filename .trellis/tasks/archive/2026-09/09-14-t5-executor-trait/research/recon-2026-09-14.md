## 方案定稿（seam）

1. **uc-types**：删 `DispatchMode::Local`；新增 `EffectClass`（ReadOnly/LocalSafe/RequiresWorker，default RequiresWorker，serde rename_all snake_case）；`Subtask.effect_class: EffectClass`（serde default）。
2. **uc-engine**：
   - 新 `scheduler/executor.rs`（旁路挂载，不改 legacy dispatch 行为——T6 才切主）：
     - `trait Executor { name/available/execute(envelope, subtask) -> Result<AttemptOutcome, ExecutorError> }`，`AttemptOutcome { status: Dispatched|CompletedLocal|Failed|Unavailable, detail, alert }`。
     - `NatsExecutor`（cfg messaging，async_nats 硬依赖 JS：publish 到 UC_SUBTASKS subject + dedup header，无 core 回退）。
     - `LocalExecutor`（注入 `LocalNodeHandler`，T5 提供测试 handler；生产真实工具执行器随 T6/T7）。
     - `SandboxExecutor`/`RemoteExecutor`：显式占位（available=false，execute → Unsupported，文档注明落地票）。
     - `ExecutorSelector::route(&Subtask, nats_available) -> Nats|Local|StayReady`：Remote 永不本地；NATS 不可用时 effect_class ∈ {ReadOnly, LocalSafe} → Local；RequiresWorker → StayReady + 告警。
   - 集成测试（tests/executor_nats_down.rs 或 src 内）：local_safe 推进、coding 停 READY + 告警、WHAT 字节不变（executor 路由不触碰 description/steps/depends_on）。
   - 删 decompose_task/steps_for_description/strip_workflow_marker + 其单测；TaskStore::submit_task → insert-only。
3. **uc-grpc**：删两处 Local no-op 分支 + conversions arms；subtask_execute_payload 增加 effect_class 字段（additive）；更新 TaskStore stale 注释。
4. **uc-grpc-server**：main.rs NATS 连接后 get-or-create UC_SUBTASKS 流（参数镜像：workqueue/7d/120s dedup，cfg messaging）。
5. **Python worker**：删 core 回退；`_ensure_jetstream_subtask_stream` 删除（gateway 供给）、consumer ensure fail-fast；JS 不可用 → `_ensure_subtask_transport` 周期重试 + 就绪前拒注册；`_registration_metadata`/心跳带 `subtask_transport`；types.py 删 LOCAL、`_dispatch_mode_from_payload` 删 local 映射、L1727 死分支删除。
6. **无头 grep 验收**（check-phase 执行并记录）：`decompose_task`、`DispatchMode::Local`、`queue="workers"`（subtask 回退）、`Falls back to core NATS` 在生产代码零匹配。
