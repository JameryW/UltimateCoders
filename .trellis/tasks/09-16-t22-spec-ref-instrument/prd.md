## Goal

T21 落地了 `scripts/check-spec-refs.py`、定下「符号优先」口径，但**这个仪器当时看不见它要服务的那个口径**：

- 它只在**行内代码**（反引号）里认符号 ⇒ `**Task**`、`### Task Properties` 这类**粗体 / 标题**写法
  一律被判成「本行没有符号」，直接**降级为不可判定**；
- 它**完全没有内容锚**的概念 ⇒ 「本行引的那段代码在目标文件里到底有没有」无从判起。

而 #673 要做的重写恰好**只能靠这两种锚**：行号一去掉，符号名与被引代码就是仅剩的证据。
⇒ 本票先把仪器补到能看见全部锚，再**量出重写的可行边界**，让重写那一刀有据可依。

## 侦察结论（全部一手实测，可复算）

### A. 锚点分布（守卫自身 `--json` 输出）

| 锚点 | 条数 |
|---|---|
| 仅符号 | 25 |
| 仅内容（本行引到的代码确实在目标里） | 41 |
| 符号 + 内容 | 18 |
| **无锚 —— 行号是唯一线索** | **64** |
| 合计 | 148 |

⇒ **今天就能去掉行号的 = 84 / 148**。余 64 条中，8 条是裸文件名歧义（`types.py` 命中多个文件），
56 条连本行都没有可匹配的被引代码。

### B. 放宽到「整段」还能再救回 21 条 —— 但本票**不**实现

把内容锚从「本行」放宽到「本行所在的段落」（向上/向下走到空行）后，64 条里 **21 条**能在段落内
找到可匹配的代码 ⇒ 可去行号 **105 / 148**，余 **35 条真正无锚 + 8 条歧义 = 43**。

⚠️ **留作下一刀的建议，本票不实现**：这把「自证」从**一行**松到**一段**，属于**语义放宽**
（候选变多 ⇒ 漏报更少，但误报风险上升），它需要自己的消融证据，不该混在本次能力补齐里。

### C. 内容锚在真实语料上**零误报**（这是它敢落地的依据）

naive 版本（原样字符串匹配）在 148 条上报 **17 处「不匹配」，其中 13 处是假阳性**：
`Worker._execute_steps` 在 `worker.py` 里**根本不会这样出现**（那里是 `def _execute_steps`）。
补上「限定名回落成末段 / 去掉 `=True` 尾巴」的归一化后：

| 结果 | 条数 |
|---|---|
| 匹配 | 85 |
| 不匹配 | 4 |
| 本行没引代码（不适用） | 51 |
| 无唯一目标（歧义） | 8 |

那 4 处是语法表里的**元变量**（`!expr` / `a && b` / `a \|\| b` / `(expr)`），**根本不是文件里的代码**
⇒ 用「被引串须含 `_` `=` `.` `"` 之一」把这类**按构造豁免**，当前语料上内容锚 **0 误报**。

### D. 更宽的符号检测：STALE 19 → 27（+8，**无一条消失**）

逐条核对新增的 8 条：**7 条是真锚**（`**Task**` ×2 / `**OrchestratorConfig**` / `**SearchResultItem**` /
`### Task Properties` / `### Subtask Properties` / `### WorkerInfo Properties`），
**1 条是散文噪声**（`error-handling.md:307` 的 `delete` 来自 "for delete operations" 这句散文）。
⇒ 精度 **7/8**，净收益明确；那 1 条噪声如实记账，不装作没有。

## 变更（单文件 `scripts/check-spec-refs.py`，numstat `108/5`）

1. **`_symbols_on` 三种写法都扫**：行内代码 + `**bold**` + `### 标题`（此前只看行内代码）。
2. **新增内容锚**：`_content_forms`（限定名/赋值式回落）+ `_content_anchor`（本行的被引代码是否在目标里出现）。
3. **内容锚是「独立标志」，不是新的 verdict** —— 刻意**不进** verdict 链：
   两条 advisory（STALE / 内容不匹配）**可以同时成立**，共用一个字段就会互相掩盖。
   这正是 T21 抓到的「两条规则写同一个字段」同型问题，只不过这次发生在**两条同级 advisory 之间**。
4. `--json` 增 `content` / `content_ok` / `content_candidate_count`，使重写那一刀**完全可由仪器驱动**。
